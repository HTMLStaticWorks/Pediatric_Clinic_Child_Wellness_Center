# LittleSteps Pediatric Clinic — Full Website

Complete responsive multi-page pediatric clinic website.

## Public pages
Home, About Us, Services, Doctors, Vaccination, Child Wellness, FAQ, Contact/Booking, Parent Login and Parent Sign Up.

## Parent portal
Dashboard, My Children, Growth Charts, Vaccinations, Appointments, Doctor Notes, Documents, Billing & Payments, Notifications and Settings. Dashboard navigation switches content within dashboard.html.

## Images
The updated version uses real pediatric/family healthcare photographs from public web sources, with unique imagery across hero, services, doctors and authentication areas. Image pages/sources should be reviewed for licensing before commercial deployment.

This is a presentation/demo website; no real patient data, payments or medical systems are connected.

## Image references
The photographic references used in this demo include public pages/results from Pexels and public healthcare/image-hosting pages. Examples include Pexels pediatric consultation photos (Pavel Danilyuk / Los Muertos Crew) and healthcare-family imagery surfaced by web image search. Verify the source license and attribution requirements for your intended commercial deployment before publishing.
